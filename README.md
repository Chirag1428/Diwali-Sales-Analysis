# Diwali-Sales-Analysis

The Diwali Sales Analysis project focuses on analyzing sales data from a retail store during the Diwali festival season. The goal is to uncover insights about customer demographics, high-performing product categories, and purchasing patterns, using Python in a Jupyter notebook environment (Google Colab).

Analysis Highlights :
1. Gender-based sales contribution

2. Age group vs. amount spent

3. Top states by revenue

4. Most profitable product categories

5. Spending habits by marital status and occupation
